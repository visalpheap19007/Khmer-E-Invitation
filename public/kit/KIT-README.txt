Khmer E-Invitation Starter Kit · by Someth Phay (somethphay.me)
================================================================
Free to use for your own wedding invitation. Please keep the credit.

elements/  (original decorative elements, made for this design)
  crest.svg      Fan-shaped crest: cover, seal, venue
  corner.svg     Corner element (top-left; mirror it inside the SVG for other corners)
  divider.svg    Section divider
  wax-seal.svg   Lit gold wax seal with the crest pressed in
  butterfly.svg  Butterfly used in the name logo
  lotus.svg      Line lotus (loader / small accents)
  All gold uses one gradient id "g-foil". Change its colours to match your card
  (e.g. silver: #8a8f96 / #d9dde2 / #ffffff).

textures/ (tileable 512x512, use as background-image, background-size ~320px)
  paper-olive.webp   Envelope paper (olive). Recolour with a CSS filter or regenerate
  paper-cream.webp   Card paper
  paper-lining.webp  Envelope flap lining

How to use with the prompt:
  Attach this whole folder (or the zip) to Claude together with the prompt.
  The prompt tells Claude to use these files instead of drawing its own.
